## 1. Purpose

The purpose of the Requirements Traceability Matrix (RTM) is to establish a clear relationship between business requirements and the project deliverables.

The RTM ensures that every requirement is:

- Clearly identified
- Properly documented
- Mapped to functional requirements
- Connected to user stories and use cases
- Supported by the data model
- Addressed through SQL analysis
- Represented in reporting requirements
- Validated through UAT

The RTM provides end-to-end traceability across the UrbanMart POS project.
