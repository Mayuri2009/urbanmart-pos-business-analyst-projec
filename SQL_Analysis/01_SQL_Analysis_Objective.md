# UrbanMart POS — SQL Analysis Objective

## 1. Purpose

The purpose of SQL analysis is to transform validated UrbanMart POS data into meaningful business insights.

PostgreSQL is used to analyze sales, products, customers, inventory, returns, payments, reconciliation and transaction performance.

The objective is not simply to write SQL queries.

The objective is to answer business questions that support decision-making.
