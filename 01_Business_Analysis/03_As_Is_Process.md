# UrbanMart POS — As-Is Process Analysis

## 1. Process Overview

The current UrbanMart POS environment contains several operational processes that generate business data.

The major process areas are:

- Customer purchase
- POS transaction processing
- Payment processing
- Inventory update
- Returns
- Loyalty activity
- Reconciliation
- Reporting
