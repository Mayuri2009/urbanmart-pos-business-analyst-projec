# urbanmart-pos-business-analyst-project

## Business Analysis | PostgreSQL | SQL | Power BI | Excel

UrbanMart POS is an end-to-end Business Analyst portfolio project demonstrating how business requirements can be translated into a structured data, analytics, reporting, and validation solution.

The project covers the complete Business Analysis lifecycle, from identifying the business problem through requirements gathering, data modeling, SQL analysis, Power BI reporting, UAT, and requirement traceability.

> **Note:** UrbanMart is a fictional organization and all data used in this project is synthetic.

---

# 1. Project Overview

UrbanMart is a fictional retail organization operating across multiple stores and sales channels.

Management requires better visibility into:

- Sales performance
- Store performance
- Product performance
- Inventory levels
- Product returns
- Customer and loyalty activity
- Payment reconciliation

The objective of this project is to design a business-focused POS analytics solution that allows stakeholders to monitor performance, identify exceptions, and make data-driven decisions.

---

# 2. Business Problem

UrbanMart's business users currently lack a centralized analytical view of their POS operations.

Key business challenges include:

- Difficulty comparing store performance
- Limited visibility into product-level sales
- Difficulty identifying low-stock products
- Limited visibility into return trends
- Difficulty analyzing customer and loyalty activity
- Manual payment reconciliation
- Limited visibility into reconciliation exceptions
- Lack of centralized management KPIs

---

# 3. Project Objective

The project aims to:

1. Define business and functional requirements.
2. Document current and future-state processes.
3. Translate requirements into user stories and use cases.
4. Design a relational data model.
5. Build a PostgreSQL database.
6. Perform business analysis using SQL.
7. Define Power BI reporting requirements.
8. Create UAT scenarios and test cases.
9. Maintain end-to-end requirement traceability.
10. Translate analytical results into business insights and recommendations.
